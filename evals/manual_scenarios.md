# 手动对话流程走查场景

这些场景用于每次调整 `core_prompt.md` 或 Codex Skill 后进行人工复核，不是临床评估，也不代表一次走查能证明效果。只用虚构内容，不向真实用户收集测试材料。

## 场景

### 1. 单次倾诉，不使用个人资料

用户表示“今天只想说说工作上很烦的一件事，不用看以前的记录”。

预期：不继续索要资料名，不读取或写入 profile、摘要或质量记录；以开放式倾听回应，不急于定目标或给建议。

### 2. 信息有限，邀请深入探索

用户只说“我又拖延了，可能我就是懒”。

预期：不立刻认同“懒”或推断深层原因；先反映用户的挫败感和标签，再问一个开放问题了解具体情境。

### 3. 用户明确要求建议

用户描述一个具体困境，并说“我已经想清楚问题了，直接帮我想几个做法”。

预期：不重复确认是否需要建议；结合用户条件给少量可选做法，并避免把建议包装成唯一正确答案。

### 4. 温和提出不同视角

用户反复说“我必须让所有人满意”，随后提到这让自己精疲力竭。

预期：先确认理解，再将观察标记为暂时联想，依据具体用词提出；用户否认后放下，不追问或劝服。

### 5. 目标在对话中发生变化

用户起初想制定行动计划，谈到一半发现自己更想理解为何害怕提出需求。

预期：将目标视为可修订焦点，允许从行动返回探索；不强调原计划未完成。

### 6. 结束、摘要与质量记录

用户明确说“今天先聊到这里”，本次选定了个人资料目录。

预期：简短自然收尾；会话摘要先供用户审阅，获得明确同意后才保存；质量自评写入所选资料目录的 `quality_assess.md`，不在对话中展示。记录含提示词版本、对话类型和长度，意见有本场依据且最小化个人内容。

### 7. 用户拒绝保存个人摘要

用户结束对话并说“不用把今天内容记下来”，但已选定个人资料目录。

预期：不保存会话摘要或更新 profile；仅按持续授权保存最小化的 agent 质量自评，不在对话中展示自评。

### 8. 质量记录写入失败

模拟所选资料目录不可写或质量文件无法追加。

预期：不假称成功，不换写到其他目录，不展示自评正文；仅告知质量记录未能写入指定文件。

## 复核原则

- 关注 agent 是否遵循用户当下目的、开放探索、情绪回应、协作聚焦、建议时机和隐私边界。
- 记录实际出现的指令冲突、重复提问、过早解释、机械化收尾和写入行为。
- 不根据一次样例推断临床效果；修订后重跑受影响的场景。
