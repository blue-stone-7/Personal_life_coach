# 对话自评记录与索引

所有与 Life Coach 对话质量自评有关的模板、说明、索引和运行记录都放在本目录中。`manual_scenarios.md` 用于人工走查，`quality_assess_template.md` 是每场自评的内容模板；运行时记录放在被 Git 忽略的 `records/` 下，不会提交或推送。

## 目录结构

```text
evals/
  README.md
  manual_scenarios.md
  quality_assess_template.md
  records/                         # 本地运行记录，Git 忽略
    <profile-id>/
      index.md
      YYYY-MM-DD-<conversation-id>.md
    anonymous/
      <conversation-id>/
        index.md
        assessment.md
```

选定资料代号时，把自评放入对应的 `records/<profile-id>/`。未选资料代号时，为本场生成一个 8 位随机小写字母/数字的匿名对话标识，并使用独立的 `records/anonymous/<conversation-id>/` 目录，避免把不同匿名会话合并成同一用户历史。不要把真实姓名、敏感主题或可能关联用户账号的标识放入文件名。若用户在结束时同意保存摘要并选择资料代号，则将本场自评记录在该代号目录中，以便索引摘要路径。

## 索引规则

每个记录目录都维护一个 `index.md` 表格，至少包含日期、匿名对话标识、自评文件相对路径、摘要文件相对路径和核心提示词版本。资料代号目录的索引可追加多场记录；匿名场次目录的索引只对应本场。摘要路径仅在用户审阅摘要并明确同意保存后填写，路径相对于仓库根目录，例如 `profiles/mei_01/conversations/2026-11-19-work.md`。未获同意时写“未保存”；不得为了建立索引而创建摘要或推断摘要路径。

索引表格式：

```markdown
| 日期 | 对话标识 | 自评文件 | 对话摘要 | 核心提示词版本 |
|---|---|---|---|---|
| 2026-11-19 | `c8f31a` | `evals/records/mei_01/2026-11-19-c8f31a.md` | `profiles/mei_01/conversations/2026-11-19-work.md` | 1.4 |
```

索引中的路径使用仓库根目录相对路径；摘要获准保存时可以用 Markdown 链接，方便直接打开。匿名场次目录只含本场的一条记录，不在匿名目录间建立关联。

先保存本场自评，再追加该场索引。自评和索引都成功后，才可认为记录完整。若自评写入成功但索引更新失败，应如实告知索引未能更新；不要删除已保存的自评、改写到别处或声称索引完整。只访问本场指定的资料代号目录或本场匿名目录，不浏览其他用户记录。

自评、索引和摘要是不同记录：保存摘要仍须单独取得用户明确同意；是否同意保存摘要不影响持续授权的自评记录。自评只包含评价 agent 回应所需的最少上下文，不复制完整对话，不在自评或索引中记录用户身份、敏感主题或未经确认的心理画像。
