# 本地 Codex 个人成长对话伙伴

本项目将个人成长对话规范作为可移植资料保存，并提供 Codex 项目技能入口。使用时由 Codex 当前登录账号和会话运行，不需要配置 OpenAI API Key，也不需要额外 Python 服务。

## 在 Codex 中使用

1. 在 Codex 中打开本仓库目录 `life-coach-agent`。跨平台迁移时请携带整个仓库；Codex Skill 会读取仓库根目录的 `core_prompt.md`，单独拷贝 `.agents/skills/life-coach/` 并不完整。
2. 开始一段新对话，在消息中调用 `$life-coach`，然后自然描述你想聊的内容。示例：

   ```text
   $life-coach 今天想聊聊我总是拖到最后一刻才开始重要任务这件事。
   ```

3. 如果技能列表没有立即显示，重载项目/重启 Codex 后再试。项目技能定义位于 `.agents/skills/life-coach/SKILL.md`。

该技能在当前 Codex 对话中应用核心提示词，不会开启独立的聊天界面或独立会话。每段新对话都可以重新调用技能。模型和用量按当前 Codex 账号及其产品规则处理；Codex 的具体账号额度和数据处理方式以应用内当前说明为准。

## 资料文件

- `core_prompt.md` 是平台无关的行为规范单一来源。
- `.agents/skills/life-coach/SKILL.md` 是 Codex 项目适配入口，并要求在使用时读取核心提示词。
- `profile_template.md` 是由用户控制的个人资料模板。
- 每场新 Life Coach 对话开头会自然确认资料代号和是否读取历史；资料代号不是身份认证。用户可以不读历史、只聊本次内容。每场结束时，agent 会询问是否留存摘要；摘要和长期 profile 仅在用户审阅并明确同意后保存。质量自评依照用户对该项的持续授权，不受摘要保存选择影响，统一写入 `evals/records/`，按资料代号或匿名场次隔离并由 `index.md` 索引；用户同意保存摘要时，索引会附摘要路径。自评不展示给用户，模板和索引规则见 `evals/`。用户资料和自评记录目录均已加入 `.gitignore`，不会随 Git 提交。
- 只想进行一次性对话时可选择不使用或读取历史资料；结束时仍可选择是否将本次摘要存入某个资料目录，也可以完全不留存。仓库编辑请求不属于 Life Coach 对话，Skill 应切换为常规 Codex 项目协作模式。

## 隐私与安全

调用 Codex 账号不等于所有数据只保存在本机。对话按 Codex 当前服务的数据处理和保留规则处理。请在 Codex 设置中查看适用的数据控制选项，并避免分享你不愿提供给该服务的敏感信息。

核心提示词界定了支持性个人成长对话与心理治疗/诊断之间的边界，并说明危机情况下优先寻求现实中的即时支持。

按资料名选择目录不等于登录认证。技能不接收或验证密码，也不能阻止有此工作区权限的人读取其他目录。不要在 Codex 对话中输入密码；需要真正隔离时，应使用不同操作系统账号/工作区权限或独立应用。

## 迁移到其他平台

迁移时以 `core_prompt.md` 为规范来源；将它适配到目标平台的系统指令或项目技能中。当前 Codex Skill 依赖根目录核心文件，因此需携带整个仓库，或在目标平台适配时显式打包该文件。平台专属调用方式应留在适配层，不要把 Codex 专属语法写进核心提示词。

调整对话规范后，可按 `evals/manual_scenarios.md` 用虚构对话进行人工走查，检查常见流程和隐私边界。
